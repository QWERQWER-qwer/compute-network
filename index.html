컴퓨터 네트워크 실습

DNS, TCP/IP, HTTPS, HTTP 프로토콜의 유기적인 동작 과정을 실습을 통해 깊이 있게 배우는 수업입니다.

핵심 실습 주제

Domain Name System (DNS)

도메인 이름을 IP 주소로 변환하고 가비아와 같은 등록대행자를 통해 레코드를 제어해 봅니다.

TCP / 3-Way Handshake

데이터 전송 전 신뢰성 있는 연결을 수립하기 위한 클라이언트와 서버 간의 제어 흐름을 이해합니다.

HTTP & HTTPS/TLS

웹 서버와 브라우저가 평문 및 암호화된 데이터를 주고받는 요청 및 응답 메커니즘을 학습합니다.

웹 페이지 접속 시 내부 동작 흐름

이 홈페이지 주소를 입력하고 화면이 보이기까지의 브라우저 비하인드 스토리

1
주소창 입력 (URL Input) 사용자가 브라우저에 도메인 주소(예: https://hyuek.store)를 입력합니다.
2
DNS 조회 (DNS Lookup) 네임서버에 질의하여 영어로 된 도메인을 컴퓨터가 찾아갈 수 있는 물리적 IP 주소로 변환합니다.
3
TCP 연결 수립 (3-Way Handshake) 정확한 데이터 송수신을 위해 SYN, SYN-ACK, ACK 패킷을 주고받으며 서버와 논리적 연결을 맺습니다.
4
HTTPS / TLS 암호화 세션 데이터 패킷 도청을 막기 위해 보안 인증서를 기반으로 통신 전 과정을 암호화합니다.
5
HTTP 요청 전송 (HTTP Request) 준비가 끝나면 웹 서버(GitHub Pages 등)에 GET / index.html 파일 양식을 요청합니다.
6
브라우저 렌더링 (HTML/CSS 화면 표시) 서버가 응답한 HTML/CSS 소스코드를 웹 브라우저가 해석(Parsing)하여 시각적인 화면으로 그려냅니다.
